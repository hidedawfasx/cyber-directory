# CyberDirectory

Интерактивный справочник по информационной безопасности и этичному хакингу. 24 темы с командами, разбором инструментов и проверочным тестом после каждой главы. Всё работает в браузере, без сборки и без зависимостей.

Оформление в стиле терминала: чёрный фон, тусклые светящиеся рамки, четыре цветовые темы плюс светлая.

## Что внутри

- **24 раздела**: обзор угроз, фишинг и дипфейки, Wireshark, Nmap, Burp Suite, SQLMap, XSS, OSINT, Hashcat, Aircrack-ng, Metasploit, мобильный пентест, OPSEC, MITM, повышение привилегий в Linux, стеганография, веб-фаззинг, Active Directory, Docker, пентест API и JWT.
- **Тест после каждой главы**: ответы проверяются сразу, неверный вариант подсвечивается красным.
- **Пять тем оформления**: Terminal (белая), Matrix (зелёная), Amber (янтарная), Cyan (голубая) и светлая.
- **Минималистичные иконки и hover-эффекты**: плитки, карточки и кнопки реагируют на наведение.
- **Адаптивная вёрстка**: боковое меню на десктопе, выезжающее меню на телефоне.

## Технологии

Чистые HTML, CSS и JavaScript. Переключение цветовых тем сделано на CSS (радиокнопки и `:has()`), JavaScript отвечает только за навигацию по разделам, светлую тему и проверку тестов.

## Запуск

Скачай репозиторий и открой `index.html` в браузере. Сервер не нужен.

## Структура

```
index.html   разметка и содержимое всех разделов
style.css    оформление и цветовые темы
script.js    навигация, светлая тема, проверка тестов
images/      SVG-иконки
```

## Важно

Материалы предназначены только для обучения, подготовки к CTF и защиты собственной инфраструктуры. Все приведённые команды запускай только на своих системах или на легальных учебных стендах.
